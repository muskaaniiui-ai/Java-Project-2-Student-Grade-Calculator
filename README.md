# Student Grade Calculator

## Project
DecodeLabs Java Programming Project 2

## Description
This Java application calculates:
- Total Marks
- Average Percentage
- Grade
The user enters marks for multiple subjects, and the program calculates the results automatically.

## Features
- Input marks
- Total marks
- Percentage calculation
- Grade calculation
- Easy console interface

## Technologies
- Java
- Scanner Class
- Loops
- Conditional Statements

## How to Run
Compile

```bash
javac StudentGradeCalculator.java
```
Run
```bash
java StudentGradeCalculator
```
